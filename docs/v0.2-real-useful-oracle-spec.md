# Looking Glass Engine — "Real & Useful Oracle" (v0.2)

## Idea
The app keeps its **oracle identity** (poetic, first-person field voice, the
consciousness-field metaphor, the region archetypes) but stops being a one-shot
poetic mirror. It becomes a **real, useful reflection tool that speaks
beautifully**: it reads the user's state through defensible methods, remembers
them across sessions and surfaces genuine patterns, lets them correct its read,
and ends every reading with a takeaway. Honesty is the differentiator — the
mystique stays in the voice, not in false claims.

## User Story
As someone seeking reflection, I want an oracle-like space that reads my state
honestly and remembers me over time, so that I walk away with something true
about myself — a pattern, a reframe, or a next step — not just a pretty echo.

---

## A. Make the reading "real" (upgrade state detection)

Replace naive keyword counting with a **hybrid locally-run pipeline**. Map each
of the three axes onto a real psychological dimension and stop overclaiming.

Currently: `state.py` scans text against hand-built word lists
(`POSITIVE_WORDS`, `URGENT_WORDS`, etc.) and heuristics. This has no validity —
it ignores negation, context, and polyvalence, and there is NO validated scale
for "arousal/depth/openness" as invented.

**New pipeline (all run locally, MIT/permissive):**

| Axis | Valid mapping | Method / tool |
|------|--------------|---------------|
| **Arousal** | Russell's valence×arousal circumplex | **NRC VAD Lexicon v2** (55k words, per-word arousal) + go_emotions `excitement`/`nervousness` + RoBERTa valence intensity |
| **Valence (new input)** | pos/neg polarity | `cardiffnlp/twitter-roberta-base-sentiment` (transformers, CPU) |
| **Depth** | Pennebaker cognitive-process "working through" | LIWC-style: **Analytic** summary + cognitive-process % (insight/cause/discrepancy/tentative/certainty) + syntax elaboration |
| **Openness (RENAME → "Self-disclosure / Receptiveness")** | not validly readable as Big-Five openness | LIWC **Authentic** + first/second-person pronoun ratio + go_emotions `curiosity` |

**Self-report anchor (the single most valid state signal):** add a compact
PANAS-derived or single-item (Self-Assessment Manikin) self-report the user can
answer in one tap. **Text read = confirmatory; self-report = primary.** This is
the difference between a gimmick and a defensible reading.

- Effort: Tier-1 hybrid ≈ 1 engineer-day; full pipeline ≈ 2–3 days.
- Libs: `transformers`, `SamLowe/roberta-base-go_emotions`,
  `cardiffnlp/twitter-roberta-base-sentiment`, NRC VAD csv + nltk/spaCy,
  `pyliwc` (MIT) or `Empath` (open-source) for LIWC-style summary vars.
- Architecture ref: `/workspace/state-detection-methods.md` §4.

**Honesty guardrails:**
- Label the three numbers "estimated tendencies — low to moderate confidence,"
  especially under ~50 words. Never present as validated psychometric scores.
- Do NOT claim to read "consciousness" or the mind. The oracle says, in its own
  voice: "I read the shape of your asking — not your mind."
- Rename "Openness" to "Self-disclosure / Receptiveness" in all UI text
  (no-ambiguity naming, per house style).

## B. Make it "useful" (the value-defining work)

1. **Active pattern surfacing (P0, the big one).** The SQLite log already stores
   everything. Build a real **Patterns / Threads** view that aggregates across
   sessions: recurring themes, mood-state ↔ context correlations, repeated
   phrasings, and **quoted echoes of the user's own past words**. This is the
   single novelty→tool switch.

2. **Mandatory takeaway (P0).** Every response ends with a closing move —
   a *reframe* (self-distancing), a *named micro-step*, a *question to carry*, or
   a *split* (controllable vs. acceptable). Explicitly forbid responses that only
   mirror the feeling ("aesthetic echolalia").

3. **Restructure the prompt (P0).** Feed the LLM three inputs: the **question**
   (context, always), the **confirmed state** (delivery/tone/pacing/distance/
   dosage — not the whole story), and **retrieved recent history** (the value).
   When distress is high, increase self-distancing and gentleness.

4. **User confirmation of state (P0).** Show the detected state; let the user
   correct/refine it (offer precise emotion-word choices — this doubles as an
   emotional-granularity exercise). Store the **user-confirmed** state as ground
   truth. Wrong automatic reads are the #1 "this is fake" signal.

5. **Multi-turn follow-ups + thread continuity (P1).** Ask follow-ups on the
   user's actual answer, not canned prompts. Support revisiting the same topic
   across sessions (Pennebaker "same topic, multiple days").

6. **Self-distancing prompts (P1).** Offer/auto-apply "advise-a-friend" framing
   ("if a close friend told you this...") especially when distress is high.

7. **Track change / delta (P1).** Surface what changed since the last touch on a
   thread: affect delta, stated intention vs. follow-through, reoccurrence counts.

8. **Goal-matched modes (P1).** Entry modes mapped to evidence: Process / Lift /
   Clarify / Find-direction / Calm. Each pulls the corresponding evidence-based
   technique + closing.

## C. Polishing & safety (P2)

- **Honest limits + distress path.** It is a reflection companion, not therapy —
  never diagnose. Include a discreet distress/help path. State expectations
  ("a mirror and a pattern-finder, not a clinician").
- **Privacy affordance.** Keep raw entries private; only reveal aggregated
  patterns (readership reduces expressive-writing benefit).
- **Consistency beats length.** Encourage short frequent sessions; "resume your
  thread" re-entry.

## D. The Aether Personality (new — "personality arises from the aether")

**Idea:** Each session, the oracle manifests with a *different personality/voice*
that "arises from the aether" — freshly drawn rather than a fixed assistant
persona. "Who the oracle is" changes from session to session.

**Honest mechanism (cast from chance, revealable seed, state as bias):**
- The "aether" is an **oracle lot-cast**: each session draws from a personality
  pool using a **seed derived from genuine chance** — e.g. session id hash,
  timestamp, day-of-week, lunar phase, and a rolling random seed. The draw is
  *seeded and deterministic* (same seed → same cast), so it is verifiable,
  reproducible, and revealable — exactly like drawing lots where you can show
  the lots.
- **Your state is a bias, not the decider.** The current state reading (arousal /
  depth / self-disclosure) *weights* the draw — e.g. a distressed quest makes a
  Gentle Witness more likely, but chance can still cast a different aspect. The
  oracle is genuinely aleatory, not a fixed function of your mood.
- Assemble a **personality vector** from the drawn archetype (each archetype = a
  distinct voice, tone, worldview — e.g. *Stern Philosopher*, *Playful
  Trickster*, *Gentle Witness*, *Fierce Oracle*, *Quiet Poet*). Optional: an LLM
  fleshes it into a concrete persona for that session.
- The personality modulates **delivery** (voice, pacing, metaphor, worldview)
  alongside state-conditioning in §B-prompt. It never replaces the "value"
  inputs (history + meaning + takeaway).
- **Constant per thread:** the cast happens once per session/thread and stays
  fixed for the whole conversation (a Stern Philosopher stays a Stern Philosopher
  across all its multi-turn follow-ups), then the aether re-casts for the next
  session. This keeps each dialogue coherent while still varying between sessions.
- **Reveal affordance:** "show this session's cast" reveals which archetype was
  drawn and the seed — the honesty is the differentiator. Mystique in voice,
  reproducibility in mechanism.

**Guardrails:**
- Never claim to be a channeled entity. If asked "who are you?", the oracle
  answers in-character *but honestly* ("I am the aspect the aether manifested
  from the shape of your asking; my seed is X").
- Personality auto-softens with distress — do not manifest a harsh/chaotic
  archetype for a user who is distressed or activated.
- Persistent memory / thread continuity is NOT lost: personality changes, but
  the oracle still remembers and surfaces patterns (the aether manifests anew,
  yet the mirror remembers).
- Every session still ends in a takeaway regardless of which personality emerged.

**Acceptance (add to AC):**
- [ ] Personality varies across sessions via a seeded oracle lot-cast (genuine
      chance), not a fixed function of state
- [ ] State reading *biases* the draw (distress → gentle witness more likely)
      but does not fully determine it
- [ ] Same seed → same cast (reproducible for testing); "show this session's
      cast" reveal affordance present (archetype + seed)
- [ ] Distress softens the manifested archetype (safety override on the draw)
- [ ] History / pattern-surfacing still works regardless of session personality
- [ ] Never claims to channel entities; reveal affordance present

**Edge cases:** reproducibility for testing; harsh-archetype+distress collision;
personality influencing takeaway style (still must give a takeaway); very short
input making the state seed thin (fall back to state-independent seed so the
voice still varies).

## Acceptance Criteria
- [ ] State detection uses the hybrid pipeline (transformers + NRC-VAD + LIWC-style
      + self-report anchor), not naive keyword lists
- [ ] "Openness" renamed to "Self-disclosure / Receptiveness" everywhere, no
      overclaiming, confidence shown
- [ ] Self-report anchor implemented; text read clearly labeled as secondary
- [ ] Pattern/Thread view aggregates sessions and quotes the user's own past words
- [ ] Every response ends in a takeaway (reframe / micro-step / question / split)
- [ ] Prompt feeds question + confirmed state + history; state only modulates delivery
- [ ] Detected state shown + user-correctable; confirmed state stored
- [ ] Follow-ups and thread continuity work across sessions
- [ ] Pill a "Not therapy" disclosure + distress path present
- [ ] No JS errors; full pipeline verified in browser against Ollama

## Constraints
- Runs locally, offline, via Ollama; no new paid services
- Must not break existing backend toggle (Ollama / OpenRouter)
- Existing `.env` secret handling + gitignore preserved
- No acronyms in UI descriptions; plain-English labels

## Edge Cases
- Very short input (<25 words): show low confidence, don't over-read
- Mixed/contradictory text: report variance, invite self-report
- User corrects detected state: confirmed state wins; text read re-weights
- Distress signals: increase self-distancing, show help path
- Long gap between sessions on a thread: show "here's what changed" delta

## Out of Scope (v1.0 of this change)
- Full therapy-grade clinical validation
- Mobile app / push at scale
- Commercial NRC-VAD licensing (verify before any paid distribution)
